# WorkBuddy 端到端设置

MiVibe Remote 使用 WorkBuddy 自带的语音输入，不重复进行语音识别。点击“WorkBuddy 预设”后：

- 电源键打开或切换到 WorkBuddy；
- 按住遥控器麦克风键开始传输语音，松开后停止并转写；
- 确定键发送，返回键退格，方向键移动光标，菜单键为 Escape。

WorkBuddy 的语音输入是开关型快捷键。MiVibe Remote 会在遥控器开始传输语音时点按一次快捷键，
在松开麦克风键时再点按一次，因此用户仍然保持“按住说、松开停”的操作习惯。

## macOS

1. 安装并运行 MiVibe Remote 和 WorkBuddy。
2. 在 MiVibe Remote 的“按键”页面点击“WorkBuddy 预设”。
3. 保持 WorkBuddy 的“切换语音录制”快捷键为默认的 `Command + D`。
4. MiVibe Remote 会自动把遥控器语音写入 `MiRemoteV 2ch`。
5. 如果 WorkBuddy 没有单独的麦克风选择项，在“系统设置 → 声音 → 输入”中选择
   `MiRemoteV 2ch`。
6. 按电源键打开 WorkBuddy，按住遥控器麦克风键讲话，松开后等待转写。

## Windows

1. 安装 MiVibe Remote Windows 包和 WorkBuddy；首次安装 MiVibe Remote 需要联网配置 VB-CABLE。
2. 打开 MiVibe Remote 的“按键与语音设置”。
3. 点击“WorkBuddy 预设”，再点击“保存并应用”。
4. 保持 WorkBuddy 的“切换语音录制”快捷键为默认的 `Ctrl + D`。
5. 如果 WorkBuddy 没有单独的麦克风选择项，在 Windows 声音设置中把输入设备选择为
   `CABLE Output`。
6. 按电源键打开 WorkBuddy，按住遥控器麦克风键讲话，松开后等待转写。

如果修改过 WorkBuddy 的语音快捷键，需要将其恢复为上述默认值，或者在 Windows 版
MiVibe Remote 中把麦克风键录制为相同快捷键并选择“开关型”。
