# MiVibe Remote 虚拟麦克风

## 为什么需要它

`MiRemoteV 2ch` 是 MiVibe Remote 提供的双声道虚拟麦克风，用来把遥控器语音送入 Codex 等听写应用。

它可以与 `BlackHole 2ch` 并存，不会修改、删除或覆盖 BlackHole。

## 安装

不需要安装 Xcode、Git，也不需要运行终端命令。

1. 在 DMG 根目录双击“安装 MiVibe Remote.pkg”。
2. 在系统安装器中按提示输入管理员密码。
3. 安装器会同时安装 MiVibe Remote 和 `MiRemoteV 2ch`，重启 CoreAudio，并自动启动 MiVibe Remote。
4. 左键单击菜单栏图标，确认首页“虚拟麦克风”显示“已就绪”。
5. 在 Codex 中选择 `MiRemoteV 2ch` 作为麦克风。

## 验证

在 QuickTime Player 中选择“文件 → 新建音频录制”，把输入设备设为 `MiRemoteV 2ch`。按住遥控器语音键说话时，输入电平应发生变化。

如果 QuickTime 有电平但 Codex 没有开始听写，请确认 Codex 的“按住听写”快捷键是 `Control + Shift + D`，然后重新单击输入框再按住语音键。

## 卸载

双击 DMG 根目录中的“卸载 MiVibe Remote 音频驱动.pkg”。它只删除：

```text
/Library/Audio/Plug-Ins/HAL/MiRemoteV2ch.driver
```

卸载后会重启 CoreAudio，不会删除 MiVibe Remote 应用，也不会修改 BlackHole。

该驱动由固定的 BlackHole `v0.7.1` 源码、项目补丁和发布构建参数生成。实际 Audio Device 报告为 USB transport，设备名为 `MiRemoteV 2ch`。
