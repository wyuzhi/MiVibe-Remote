# MiVibe Remote 0.1.14 首次安装说明

## 使用要求

- Apple Silicon Mac；
- macOS 15 或更高版本；
- 小米蓝牙遥控器 2（macOS 内部型号可显示为 RC001）。

应用使用 ad-hoc 签名，DMG 内的两个 PKG 未使用 Installer 证书签名，当前均未进行 Apple 公证。请只安装来自你信任来源的文件。

## 安装

打开 `MiVibe-Remote-0.1.14.dmg` 后，推荐双击“安装 MiVibe Remote.pkg”。安装器会：

1. 把“MiVibe Remote.app”安装到“应用程序”；
2. 安装虚拟麦克风 `MiRemoteV 2ch`；
3. 重启 CoreAudio；
4. 为当前桌面用户启动 MiVibe Remote。

推荐始终使用安装包完成应用和虚拟麦克风安装。仅把 App 拖到 Applications 不会安装语音所需的虚拟麦克风。

若系统阻止安装，请前往“系统设置 → 隐私与安全性”，确认文件来自你信任的来源后选择继续打开。

## 配对遥控器

1. 在 Mac 蓝牙设置中打开蓝牙。
2. 同时长按遥控器“主页”和“菜单”键，使遥控器进入配对状态。
3. 在 Mac 上连接“小米蓝牙语音遥控器”、`MI RC` 或 `Xiaomi Bluetooth Remote 2 Pro`。

## 权限

首次启动后按提示允许蓝牙权限。

如果需要自定义普通按键，还要在“权限”页面依次允许输入监控和辅助功能。授权后请完全退出并重新打开 MiVibe Remote。

## 配置语音输入

1. 左键单击菜单栏中的 MiVibe Remote 图标。
2. 首页确认“虚拟麦克风”为“已就绪”；应用会自动选择 `MiRemoteV 2ch`。
3. 在 Codex 中选择 `MiRemoteV 2ch` 作为麦克风。
4. 单击 Codex 输入框，按住遥控器语音键说话，松开后结束。

全新安装已默认启用 Codex 按键映射：电源打开 Codex、确定发送、返回为 Delete、菜单为 Escape。若之后改过按键，可在“按键”页面点击“Codex 预设”恢复；也可选择“WorkBuddy 预设”或“微信预设”。

可以先在 QuickTime Player 的“新建音频录制”中选择目标设备，确认按住语音键时有输入电平。

## 卸载

1. 退出 MiVibe Remote。
2. 双击 DMG 中的“卸载 MiVibe Remote 音频驱动.pkg”，移除 `MiRemoteV 2ch`。
3. 删除“应用程序”中的“MiVibe Remote.app”。

卸载 PKG 不会修改或删除已有的 BlackHole。

## 隐私与许可

MiVibe Remote 不上传或保存语音，日志不记录语音内容、蓝牙地址或外设 UUID。
启用“保持虚拟麦克风为默认输入”时，应用运行期间会保持 `MiRemoteV 2ch` 为
默认输入，但空闲时不会打开采集通道；退出应用后会恢复启动前的输入设备。

项目软件代码与原创 App 图标采用 `GPL-3.0-only` 许可。上游来源和第三方许可材料保留在应用包内。
